04 — Autonomous Patch Agent & Trust Chain

🤖 Autonomous Patch Agent — 5 Steps
1
Download & Build
Fetches package, verifies SHA256, runs hermetic build inside sandbox. Output: BuiltArtifact with reproducibility flag.
2
Multi-Engine Scan
All 8 scan engines run in parallel. Findings deduplicated and severity-sorted. Output: []Finding.
3
Claude AI Triage
Claude receives findings + package metadata. Returns: severity, confidence, exploitability rationale, agentic risk score, patch suggestion.
4
Patch Planning
Multi-turn tool-use loop identifies affected manifest files (package.json, requirements.txt, go.mod, Gemfile, Cargo.toml). Generates PatchPlan with auto_apply flag.
5
Execute & Review
Executor applies patches (dry-run by default). Claude reviewer assesses risk. --apply writes changes. Output: full report.
🔐 Trust Chain — SLSA Level 3
A
Hermetic Build
Isolated environment, no network post-fetch. Deterministic output. Reproducibility flag in artifact metadata.
B
Artifact SHA256
SHA256 computed from BuiltArtifact content. Stored in attestation and SBOM. Used for later verification.
C
ECDSA Signing
Ephemeral ECDSA keypair generated. No key management needed — keyless via Sigstore OIDC token exchange.
D
Rekor Transparency Log
Signed attestation published to Rekor. Returns log_id + log_index. Tamper-evident, publicly auditable.
E
SLSA v1.0 Provenance
in-toto statement with build invocation, materials, byproducts, completeness. Satisfies SLSA Level 3.

05 — How to Operate

🚀 1. Install & Update Signatures
# Curl installer (auto-detects platform) $ curl -fsSL https://raw.githubusercontent.com/mah3sec/forgeguardian/main/install.sh | sh # Install modes (FORGEGUARDIAN_INSTALL_MODE) # auto default — probes GitHub, falls back gracefully # local use locally built binary # offline air-gapped bundle (set FORGEGUARDIAN_LOCAL_BUNDLE=) # minimal CLI only (no optional tools) # full all optional tools + signatures # dev symlinks from repo working tree $ export FORGEGUARDIAN_INSTALL_MODE=offline $ export FORGEGUARDIAN_LOCAL_BUNDLE=/path/to/bundle.tar.gz $ curl -fsSL https://raw.githubusercontent.com/mah3sec/forgeguardian/main/install.sh | sh # Or via Go $ go install github.com/mah3sec/forgeguardian/cmd/fgctl@latest # Download community signatures $ fgctl update
🔑 2. Set API Key
# Required for AI features $ export ANTHROPIC_API_KEY=sk-ant-... # Persist across sessions $ echo 'export ANTHROPIC_API_KEY=sk-ant-...' \ >> ~/.zshrc $ source ~/.zshrc
🛡️ 3. Scan a Package
# Basic scan $ ./fgctl scan \ --recipe=npm \ --package=lodash \ --version=4.17.20 # JSON output $ ./fgctl scan ... --json | jq . # CI — fail on HIGH $ ./fgctl scan ... --fail-on=high # New flags (v1.2.0 / v1.3.0) # --verbose · --debug verbosity levels # --prod-only / --exclude-dev skip devDependencies # --ci quiet + SARIF + fail-on=high (pure stdout, v1.3.0 fix) # --executive summary-only output # --no-banner / --no-color suppress ASCII art / ANSI # --format=json|sarif pure machine output (v1.3.0: no banner leak)
🤖 4. AI Advisory
# Generate advisory (needs API key) $ ./fgctl advisory \ --recipe=npm \ --package=lodash \ --version=4.17.20 \ --json # Output includes: # severity, confidence, exploitability, # agentic_risk, patch_suggestion
📋 5. Generate SBOM
# CycloneDX JSON $ ./fgctl sbom \ --recipe=npm \ --package=chalk \ --version=5.3.0 \ --format=cyclonedx-json \ --out=chalk-sbom.json # Formats: cyclonedx-json, cyclonedx-xml, # spdx-json, spdx-tv
✍️ 6. Sign & Verify
# Sign (keyless Sigstore) $ ./fgctl sign \ --recipe=npm \ --package=chalk \ --version=5.3.0 \ --out=chalk.att.json # Verify $ SHA=$(jq -r '.sha256' chalk.att.json) $ ./fgctl verify \ --attestation=chalk.att.json \ --sha256=$SHA
📜 8. Policy-as-Code
# Create default policy $ fgctl policy init # Block high+ findings, enable typosquat blocking $ fgctl policy set fail_on=high $ fgctl policy set block_typosquatting=true # Deny a specific package $ fgctl policy set deny_packages=evil-pkg # Show + validate $ fgctl policy show $ fgctl policy validate
🔧 9. Doctor --fix + Webhooks
# Auto-repair your environment $ fgctl doctor --fix # [PASS] grype — installed (v0.79.0) # [PASS] semgrep — installed (v1.72.0) # [FIX] policy — created ~/.forgeguardian/policy.yaml # [PASS] signatures — fresh (updated 2h ago) # [PASS] docker — running (v26.1.4) # [PASS] node — v20.14.0 (≥20 required) # [WARN] dashboard dist — run: make dashboard-build # [PASS] config yaml — ~/.forgeguardian/config.yaml valid # Signature runtime statistics (v1.3.0) $ fgctl stats # ForgeGuardian Runtime Statistics # Detection signatures: 2413 | Malware patterns: 183 | Typosquat targets: 94 $ fgctl stats --json | jq .total_signatures # Configure Slack notifications $ fgctl config set \ notify.slack_webhook_url=https://hooks.slack.com/... $ fgctl config set notify.on_severity=high
🤖 7. Autonomous Patch Agent — Full Pipeline
DRY-RUN (default — no files changed, safe anywhere)
$ ./fg-agent \ --recipe=npm \ --package=lodash \ --version=4.17.20 \ --project-dir=./my-project
⚠ APPLY (writes to manifests — run in VM or container)
$ ./fg-agent \ --recipe=npm \ --package=lodash \ --version=4.17.20 \ --project-dir=./my-project \ --apply
